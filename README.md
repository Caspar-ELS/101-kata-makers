# Inventory system

## Phase 1:
Create an inventory system read csv file the csv file should contains:

ID, product name, quantity

if CSV file __exist__ and consist of some data: display it

if CSV is __not exist__ OR it is __blank__: create a CSV with 2 dummy data

## Phase 2:
Allow user choose different operation (yes, they got 1 option only):
add item

When adding an item, user should input:

1. product name (should not empty)
2. quantity (should >= 0)

if input is invalid, display an error message

ID should generated automatically and should be unique
